# SkinLib
Modding libary for Raid: WW2 to easily add new skins to the game.

Check out the [Step-by-Step guide](doc/guide.md), the [API reference](doc/api.md) or the [examples](doc/examples/timelines_skinlib_fluent) on how to create skins.
